# 6thcents plugins for Claude Code

A plugin marketplace for [Claude Code](https://claude.com/claude-code).

## Add the marketplace

In Claude Code:

```
/plugin marketplace add 6thcents/claude-plugins
```

Then install a plugin:

```
/plugin install solution-factory@6thcents
```

## Plugins

| Plugin | What it does |
|---|---|
| [solution-factory](plugins/solution-factory) | Structured software delivery: capture decisions and constraints, break epics into small scored stories, and implement them one at a time or as an unattended epic run with planning, testing, code review and security review gates. |

## Updating

```
/plugin marketplace update 6thcents
```
